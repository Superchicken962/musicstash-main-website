MusicStash.app

MusicStash is a music player that is designed to be simple and easy to use. It allows for file importing, or direct download from YouTube.

Client / Server

Web Player

The Desktop Application (Client) is the original MusicStash application. With the client, you are given a Master Stash where all your imported music will reside. You can create your own Stashes and add any song that you have imported into your Master Stash.

Importing music is simple. If you have your own mp3 files, you can do a local import which will copy the file into MusicStash. Otherwise, you can download songs directly from YouTube into your Master Stash.

Download

The Web Player is an external website that allows you to play your music on other devices. It has been designed as a non-standalone mobile version of the client. Provided with a server address, the web player will show all user-created Stashes (Not the Master Stash) and allow for a similiar experience to the desktop app.

The desktop application comes with a server manager, which will allow you to host your MusicStash and connect via the Web Player. You may require Port Forwarding capabilities on your network if you wish to connect from outside of the network of the client. Otherwise, you can use the local network address and port to listen on a different device.
